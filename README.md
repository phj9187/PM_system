# PM_system

의사결정, 실행, 자원관리, 기록을 연결하는 조직 운영 시스템입니다.
의사결정 파트의 첫 실행 버전으로, 목표·작업·결정 요청을 관리하는 타임라인 대시보드를 제공합니다.
실행·자원관리 자동화와 Discord·Notion·AI 연결은 아직 구현하지 않았습니다.

기본 링크는 현재 사용자의 Colab 전용 접속 경로입니다. 다른 사람에게 공유하려면 선택 셀의
`PUBLIC_LINK = True`를 설정하세요. 이 경우 **Colab 임시 환경에만** Gradio를 설치해 공유 터널을 만듭니다.
링크를 가진 사람은 같은 데이터를 읽고 편집할 수 있습니다. 사용자별 권한은 아직 없습니다.
공유 링크와 서버는 임시이며 런타임 종료 또는 터널 만료 시 사용할 수 없습니다.
**Colab 초기화 시 저장 데이터가 사라질 수 있으므로 종료 전에 상단의 백업 저장을 사용하세요.**
노트북 실행 출력은 저장소에 커밋하지 않습니다.

> 이 변경을 `main`에 병합하기 전에는 위 GitHub Colab 버튼이 이전 버전을 엽니다.
> 작업 브랜치의 노트북 또는 내려받은 `notebooks/PM_system.ipynb`를 Colab에 업로드해 실행하세요.

## 구현된 기능

- 프로젝트 제목·목적·성공 조건·시작일·종료일 편집
- 세부 목표와 결정 요청 추가·수정·완료·삭제
- 작업의 담당자·상태·날짜·내용·선행 작업·연결 목표 편집
- 실제 날짜에 비례하는 중심 타임라인과 작업 가지, 기간 막대, 오늘 표시
- 가로 이동, 빈 공간 드래그, 버튼 또는 Ctrl+휠 확대·축소, 전체 맞춤
- 타임라인 바깥의 고정 목표·결정 요청·지연/차단 정보
- JSON 파일 저장, 백업 다운로드·복원, 동시 수정 충돌 감지
- 내 프로젝트 목록: 여러 프로젝트를 만들고, 프로젝트마다 기간·내 임무·결정 대기를 보고 그 프로젝트의 처음 시작 창으로 들어감. 로그인 전까지는 내 이름을 직접 입력
- 처음 시작 창: 두 하위 창(대시보드·개인별 임무)의 요약과 입구, Discord 팀 채팅 안내, 지금 확인할 일(기한 지난·차단 작업, 결정 대기)
- 앱 틀: 상단(휴대폰은 하단) 탭으로 처음 창·대시보드 창·개인별 임무 창 전환. 팀 채팅은 앱에 만들지 않고 Discord로 대체(연결은 이후 단계)
- 개인별 임무 창: 담당자를 고르면 그 사람의 작업을 지연·차단 / 진행 중 / 예정 / 완료로 나눠 보여 주고, 누르면 편집 창이 열림
- 설치형 앱(PWA): 서버로 열면 Chrome·Edge의 설치 버튼 또는 휴대폰의 "홈 화면에 추가"로 설치. 화면 파일만 보관하고 데이터는 항상 서버에서 받음(https 또는 localhost에서만 동작)

정보 정리와 사람이 판단할 수 있는 현황 제공이 목적입니다. AI 자동 결정·자원 배정은 수행하지 않습니다.

## 내 컴퓨터에서 실행 (설치 불필요)

**간단히 확인:** `dashboard/index.html`을 Chrome에서 직접 열어도 목표·작업 편집이 동작합니다.
이 모드는 서버 없이 해당 브라우저 저장소에 저장하므로 다른 기기·사용자와 동기화되지 않습니다.
브라우저 데이터 삭제나 파일 위치 변경에 대비해 백업 저장을 사용하세요.
백업 파일은 Colab 대시보드의 백업 불러오기로 옮길 수 있습니다.

**파일 저장 서버로 실행:**

Python 3.10 이상에서 저장소 루트에서 실행합니다.

```sh
python -m dashboard.server
```

터미널에 출력되는 전용 링크를 브라우저에서 여세요. `data/private/projects/`에 프로젝트마다 파일 하나로 저장되며(이전 `dashboard.json`은 첫 프로젝트로 옮겨짐)
이 경로는 Git에서 제외됩니다. 접속 키를 포함한 URL을 공개 저장소에 올리지 마세요.
저장 실패 또는 잘못된 백업 파일은 오류로 표시하며 기존 정상 데이터를 유지합니다.
백업 복원은 현재 상태를 교체합니다. 삭제된 목표·작업에 대한 참조는 해제됩니다.

검증:

```sh
python -m unittest discover -s tests -v
node --check dashboard/app.js
node --test tests/dashboard_frontend.test.cjs
```

브라우저 코드는 `dashboard/app.js`, 화면 스타일은 `dashboard/index.html`에 있습니다.

노트북 소스 재생성:

```sh
python scripts/build_notebook.py
```

## 설계 범위

| 영역 | 현재 방향 |
| --- | --- |
| 의사결정·통합관제 | 목표와 주요 정보를 고정 표시하고, 실제 시간에 비례한 가지형 타임라인으로 진행 상황 탐색 |
| 실행·자원관리 | 작업 조건·팀원 상태·가용 자원을 연결해 작업 배정과 수행 지원 |
| 기록 | 대시보드와 Discord의 진행 내용을 주기적으로 정리하여 Notion에 저장 |
| 공통 백엔드 | Colab에서 데이터 흐름·정제·검증·AI 처리·저장 연결을 개발하고 검증 |

저장소, 공통 데이터 형식, 승인 규칙, 기록 주기, AI 개입 조건과 실제 운영 환경은 아직 미정입니다.
Colab은 개발·검증 환경이며, 상시 운영 환경은 별도로 결정합니다.

## 현재 파일

- `build_design.py`: Python 표준 라이브러리로 예시 화면 SVG 생성
- `designs/01-overview.svg`: 전체 보기 예시
- `designs/02-detail.svg`: 확대 보기 예시
- `CONTRIBUTING.md`: 공동 개발 방식
- `dashboard/server.py`: 의존성 없는 저장·검증·접속 인증 서버
- `dashboard/index.html`: 실제 편집 및 타임라인 탐색 화면
- `dashboard/colab.py`: Colab 전용 링크와 선택적 Gradio 공유 연결
- `notebooks/PM_system.ipynb`: 소스를 포함한 독립 실행 노트북
- `scripts/build_notebook.py`: 실행 노트북 재생성
- `tests/test_dashboard.py`: 저장·복원·충돌·선후관계·HTTP 검증

화면의 이름·일정·수치는 예시이며 실제 팀 운영 정보가 아닙니다.
